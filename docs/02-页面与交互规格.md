# 02 — 页面与交互规格

> 登录方式已定案：`login_name` + 密码（非邮箱/手机）。设备认领不在本仓。

## 登录

- 账号（login_name）+ 密码；注册成功后切回登录
- 失败提示直接展示后端 `detail`（后端已防枚举）
- 401 清 token 并跳回登录页

## 设备资产

- 列表：名称、设备核心 ID（MAC/SN）、绑定码、认领/在线、最近活跃
- 搜索：名称/绑定码/平台 ID 模糊搜；MAC/SN 精确 lookup
- 真分页：`limit=20` + offset 上一页/下一页
- 详情：复制/轮换绑定码；**不得**调用用户 `/devices/bind`，不得改 `user_id`
- 侧栏「人设 / 历史 / 记忆 / 分析 / 外设」以最近选择设备跳进详情对应 tab

## 人设（V0.2 核心）

- 太阳星座（中文展示、英文键提交）+ 16 型 MBTI
- dossier 六字段：身份 / 背景 / 角色 / 目标 / 进化规则 / 关系
- `follow_latest` 开关 + 当前 `kb_version` 只读展示
- 高级配置 `overrides`（JSON）
- 未认领设备禁写（后端 409）
- 保存后提示「下一次设备会话生效」

## 对话历史

- 管理端只读脱敏内容；时间窗筛选 + offset 分页
- **不提供删除**（删除属于用户端）

## 记忆

- 列表：标题、正文、来源、状态；关键词/状态筛选 + 分页
- candidate 接受 / 驳回
- 不提供用户侧新建/编辑入口（管理端职责是审核）

## 分析

- 按 kind 筛选：`daily_summary` / `persona_growth`
- 卡片展示摘要、主题、情绪、跟进建议、成长建议/证据/置信度
- 禁止直接展示原始 JSON
- 无记录时为空态：等待 worker 在会话结束后产出

## 外设状态

- 只读：emotion / gaze / closed / updated_at / 扩展字段
- 无上报时展示可恢复空态

## 知识库（admin）

- 星座/元素与 MBTI：按状态/键值筛选、分页
- 草稿创建/编辑 payload（JSON）+ 不可逆发布确认
- 反馈候选：接受 / 忽略
- 仅 `role=admin` 可见菜单

## 系统

- 外链：小智智控台 URL（`VITE_XIAOZHI_CONSOLE_URL`）
- 登出
- 导出入口：后端 `/export` 仍为 501，本仓不画成可用
