# 02 — 页面与交互规格

## 登录

- 邮箱或手机（待产品拍板）+ 密码  
- 失败提示不泄露用户是否存在（安全）  

## 设备

- 列表：名称、在线、固件、capability 摘要  
- 绑定：输入/扫码 device_uid（MAC/UUID）  
- 详情：能力开关只读；链到「人设」「历史」  

## 人设（V0.2 核心）

- 选择太阳星座 + MBTI（或简短问卷）  
- 忌口/overrides 文本  
- `follow_latest` 开关 + 当前 `kb_version` 展示  
- 保存后提示「下次会话生效」  

## 对话历史

- 按设备、日期筛选；分页  
- 支持按日删除；二次确认；成功后刷新  

## 记忆

- 列表：标题、标签、source、status  
- 新建/编辑/删除  
- candidate 一键通过/驳回  
- 搜索（标题/正文）  

## 分析

- 按 kind 查看日摘要、运势小记等只读卡片  
- 可显示「生成中/失败」状态  

## 外设状态

- 只读：emotion / gaze / closed / updated_at  
- 无设备时展示空态  

## 知识库（admin）

- 按 level 浏览 element / sign  
- 编辑 payload（表单或 JSON）  
- 发布按钮 + 版本号  
- 反馈候选列表：接受/忽略  

## 系统

- 外链：小智智控台 URL（配置项）  
- 登出；（可选）导出我的数据入口
