## 后端接口可用状态（截至 2026-08-01）

服务已部署在阿里云 `39.107.143.71`，web-api 容器端口 **8010**；但安全组/UFW 只放 22/80/443，**公网直连 8010 不通**，联调两种方式：

```bash
# 方式一：SSH 隧道（推荐，连服务器真实数据）
ssh -L 8010:127.0.0.1:8010 aliyun-aipet
# 然后前端用 VITE_API_BASE=http://localhost:8010/api

# 方式二：本地起整套后端（ai-pet-backend 目录）
cp .env.example .env
docker compose up -d
docker compose run --rm web-api alembic upgrade head
```

| 接口 | 状态 | 说明 |

备注：

- 登录方式已定案为 **login_name + 密码**（通用登录名，非邮箱/手机），A2 按此做。
- 服务器上已有测试账号 `tester01`；本地方式二可自行 register。
- 鉴权细节：JWT 有效期 1440 分钟，claims 含 `sub`/`role`；401 → 跳登录页。
- FastAPI 自带 `GET /openapi.json` 与 `/docs`（Swagger UI），可拉取给前端生成 TS 类型。
- 完整契约：`../ai-pet-backend/docs/06-HTTP-API规范.md`；部署细节：`../ai-pet-backend/docs/09-部署进度与运维.md`。

## 使用约定

1. 开始某任务 → 把行从「待办」挪到「进行中」并 @ 自己；
2. 代码合入但需后端联调 → 挪到「待联调」；
3. 联调通过 → 挪到「已完成」并写日期；
4. 跨仓阻塞事项优先登记在「待联调」，每周过一遍。
